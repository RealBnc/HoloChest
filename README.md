# HoloChest

A client-side Fabric mod that projects interactive 3D holographic container interfaces in-world with smooth lid opening animations, item flight effects, dynamic multi-language localization, and remote interaction.

Works across all modern Minecraft versions (**1.21 – 1.21.11** and **26.1 – 26.3**).

## Features
- **In-World 3D Holograms:** Interactively view and manage any container (Chests, Double Chests, Ender Chests, Shulker Boxes, Barrels, Hoppers, Furnaces, Blast Furnaces, Smokers, Crafters, Dispensers, Droppers) directly in the world without a full-screen pause screen.
- **Dynamic Lid Animations:** Targeted containers realistically animate open and closed as you hover and look away.
- **Interactive Remote Access:** Click or middle-click slots to open, take, swap, and manage items remotely up to reach distance.
- **Item Flight Effects:** Interactive particle and item flight animations when items are transferred.
- **Dynamic Multi-Language Support:** Fully localized container titles and tooltips matching your Minecraft client language (English, Turkish, German, French, Spanish, Russian, Chinese, Japanese, Korean).
- **Standalone & Lightweight:** Zero external library dependencies (no m4lib required). 100% client-side.
- **Cross-Mod Compatibility:** Fully compatible with Sodium, Iris, ImmediatelyFast, and ModernFix.
