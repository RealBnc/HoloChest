# HoloChest

A client-side Fabric mod that projects interactive 3D holograms of container inventories directly in the world.

Works across all modern Minecraft versions (**1.21 – 1.21.11** and **26.1 – 26.3**).

## ⚠️ Requirements
HoloChest strictly requires **[m4lib](https://modrinth.com/mod/m4lib)** to work:
- **Modrinth:** [Download m4lib](https://modrinth.com/mod/m4lib)
- **GitHub:** [m4ssivee/m4lib](https://github.com/m4ssivee/m4lib)

## ⚠️ Multiplayer Notice
HoloChest is designed for **Singleplayer** worlds only. It does not work on multiplayer servers due to server-side container packet handling and anti-cheat restrictions.

## Controls
- **V (Default):** Toggle/lock the hologram in place and release the mouse cursor.
- **Left Click:** Pick up / place items in slots.
- **Right Click:** Pick up half / split stacks.
- **Shift + Click:** Quick-transfer items between container and player inventory.
- **Mouse Middle Click (Scroll Wheel):** Automatically sort container items by category (tools, armor, ores, materials, etc.).
- **ESC:** Instantly close the active hologram.

## Supported Containers
Works with Chests, Double Chests, Ender Chests, Shulker Boxes, Barrels, Hoppers, Furnaces, Blast Furnaces, Smokers, Crafters, Dispensers, and Droppers.
